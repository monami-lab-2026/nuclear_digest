How to install

기기별 설치 방법

안드로이드지금 기기

크롬 · 삼성 인터넷
  1. 크롬에서 사이트 주소를 엽니다.
  2. 위의 「앱 설치하기」 버튼을 누르거나, 오른쪽 위 ⋮ 메뉴 → 「앱 설치」 (또는 「홈 화면에 추가」).
  3. 「설치」를 누르면 홈 화면에 아이콘이 생깁니다.

아이폰 · 아이패드지금 기기

사파리
  1. 사파리에서 사이트 주소를 엽니다. (다른 브라우저 앱은 iOS 버전에 따라 안 될 수 있어요)
  2. 아래쪽 가운데 공유 버튼(네모에 위 화살표)을 누릅니다.
  3. 목록을 내려 「홈 화면에 추가」 → 오른쪽 위 「추가」.

PC · 맥지금 기기

크롬 · 엣지
  1. 크롬이나 엣지에서 사이트 주소를 엽니다.
  2. 위의 「앱 설치하기」 버튼을 누르거나, 주소창 오른쪽의 설치 아이콘(⊕ 또는 모니터 모양)을 누릅니다.
  3. 시작 메뉴·바탕화면(맥은 Launchpad)에서 별도 창으로 열립니다.

FAQ

자주 묻는 것

  • 업데이트는 어떻게 하나요?필요 없습니다. 뉴스는 매일, 논문은 매주 사이트에서 자동으로 바뀌고, 앱은 열 때마다 최신 내용을 받아옵니다.
  • 인터넷이 없을 때도 열리나요?마지막으로 본 페이지는 열립니다. 새 내용은 다시 연결되면 받아옵니다.
  • 지우려면?안드로이드·아이폰은 아이콘을 길게 눌러 삭제, PC는 앱 창의 ⋯ 메뉴 → 「제거」.
  • 개인정보를 모으나요?아니요. 로그인·회원가입이 없고, 밝은/어두운 화면 선택만 기기 안에 저장됩니다.
